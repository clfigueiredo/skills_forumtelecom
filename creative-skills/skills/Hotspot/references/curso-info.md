## Descrição detalhada do conteúdo

### Módulo 1 - Hotspot no MikroTik

Esse módulo é 100% prático e técnico, voltado para ensinar do zero como implantar e personalizar um servidor Hotspot profissional com MikroTik RouterOS.

O aluno inicia entendendo como funciona o recurso de Hotspot, navegando pelo menu completo da ferramenta no RouterOS e montando um laboratório controlado dentro do EVE-NG, simulando um ambiente real de provedores, prefeituras ou empresas.

As aulas cobrem:

* Criação do servidor Hotspot com pool de IPs, DHCP, DNS e autenticação
* Testes de login, logout e redirecionamento automático
* Implantação de um servidor Linux leve dentro do EVE-NG para hospedar páginas de autenticação e scripts
* Personalização completa da página de login com HTML, CSS e integração com IA
* Projeto Prefeitura com página personalizada de autenticação para redes públicas Wi-Fi
* Criação de página de login do zero com IA
* Configuração dos Profiles de usuário, com limites de velocidade, tempo de sessão, políticas e controle de banda

Ao concluir este módulo, o aluno entende a lógica do Hotspot MikroTik, domina as tabelas de firewall, NAT e redirects, e está pronto para integrar o sistema web.

### Módulo 2 - Sistema Web de Hotspot

Este é o coração do curso, onde o aluno aprende a implantar o painel administrativo completo desenvolvido pela Forum Telecom, conectando o Hotspot MikroTik com FreeRADIUS, banco de dados, pagamentos via PIX e Mercado Pago e automação via WhatsApp.
