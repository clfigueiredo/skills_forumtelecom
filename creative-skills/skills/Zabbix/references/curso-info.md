## Descricao detalhada do conteudo

### Modulo 1 - Linux e Fundamentos

O curso comeca preparando o ambiente Linux, base essencial para o Zabbix.

O aluno aprende:

* Instalar o Ubuntu Server e entender seu funcionamento basico
* Executar comandos fundamentais do terminal, como navegacao, permissoes e pacotes
* Realizar manutencao de usuarios, servicos e logs
* Alterar a porta SSH padrao para aumentar a seguranca
* Configurar o ambiente para receber o Zabbix Server com boas praticas

Essa base garante que mesmo alunos iniciantes em Linux consigam acompanhar os modulos seguintes com seguranca e autonomia.

### Modulo 2 - Zabbix 7

O modulo principal cobre o Zabbix 7.0, versao LTS mais atual.

As aulas mostram:

* Instalacao passo a passo do Ubuntu Server e do Zabbix 7, via pacote oficial e script automatizado
* Instalacao e integracao do Grafana para criacao de dashboards visuais
* Adicao de hosts via SNMP para coletar dados de switches, roteadores, MikroTiks e servidores
* Monitoramento de hosts Windows e Linux com instalacao de agentes
* Cenario avancado com ZeroTier para monitorar hosts atras de CGNAT
* Importacao de templates prontos e personalizados
* Criacao de dashboards no Grafana com graficos, alertas e paineis dinamicos
* Backup e restauracao de todo o ambiente Zabbix e Grafana
* Atualizacao do Zabbix 6 para o 7 via script, mantendo a base de dados intacta

Este modulo entrega um ambiente de monitoramento corporativo completo, profissional e pronto para producao.

### Modulo 3 - Integracoes e Notificacoes

Esse modulo e dedicado a automacao de alertas e comunicacao em tempo real.

O aluno aprende:

* Instalar uma API de WhatsApp
* Integrar o Zabbix para enviar alertas automaticos via WhatsApp
* Configurar notificacoes pelo Telegram, criando bots, tokens e acoes de disparo
* Criar acoes inteligentes e condicoes para evitar spam e priorizar alertas criticos

Ao final, o Zabbix passa a notificar automaticamente quedas, falhas e alertas de performance, com envio instantaneo para equipes tecnicas ou grupos de suporte.

## Resultado final

Ao final do curso, o aluno possui um ambiente corporativo de monitoramento centralizado, com dashboards modernos, alertas automaticos e controle total sobre servidores, roteadores, switches, sistemas e aplicacoes.
